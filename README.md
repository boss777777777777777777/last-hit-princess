# あと一撃のプリンセス

3ステージの横スクロールアクション。PCとスマートフォンのブラウザで遊べます。

## 遊び方

- 移動：左右キー / A・D
- ジャンプ：Space / ↑ / W / Z（長押しで高く跳べます）
- 星で攻撃：X / J（長押しで連射）
- 一時停止：Esc / P
- スマートフォン：画面下のボタンで操作
- 敵は上から踏んでも倒せます。チェックポイントでは体力が回復します。

## ステージ

1. はじまりの草原
2. 星空の渡り道
3. ピーチ姫の城

1・2面はクリアできます。最終ボスのピーチ姫は、体力が1になると無敵になります。最後の一撃の直前、冒険者がうっかりスカートの中を見てしまい、鼻血・めまい・貧血で必ずゲームオーバーになるコミカルな演出です。ステージ3から勝利状態へ進む経路はありません。何度でもボス戦に再挑戦できます。

## 動かし方

`index.html` を開くだけで動きます。ライブラリのインストールやビルドは不要です。GitHub Pages は main ブランチのルートから公開できます。

進行状況は今回のプレイ中だけ保持します。アカウント登録や広告はありません。ゲームの進行状況は外部に保存しません。グラフィックと効果音はオリジナルです。

非公式ファンゲームです。ピーチ姫などの名称は、それぞれの権利者に帰属します。
